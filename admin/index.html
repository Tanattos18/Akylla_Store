Entrar no painel

O painel salva as mudanças direto no GitHub, que publica o site em cerca de 1 minuto. Para isso ele usa uma chave de acesso que só você tem.

Como criar a chave (uma vez só)
  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token (endereço: github.com/settings/personal-access-tokens/new).
  2. Nome: Painel Akylla. Validade: 90 dias (renove quando vencer).
  3. Repository access: Only select repositories → Akylla_Store.
  4. Permissions → Repository permissions → Contents: Read and write. Não marque mais nada.
  5. Gere, copie a chave (começa com github_pat_) e cole aqui.

Só marque “Lembrar neste aparelho” no seu celular ou computador pessoal. Se perder o aparelho, apague a chave no GitHub.
